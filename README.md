# Homebrew tap

Homebrew tap for [Ventilador](https://github.com/ulm0/ventilador), fan control for Apple Silicon Macs.

## Install

Add the tap once, then install the cask:

```bash
brew tap ulm0/tap
brew install --cask ventilador
```

Or do both in one step:

```bash
brew install --cask ulm0/tap/ventilador
```

Then open Ventilador, click **Enable Fan Control** in the menu bar popover, and approve it in
*System Settings > General > Login Items & Extensions*.

Requires an Apple Silicon Mac and macOS 26 or later.

## Update and remove

```bash
brew update                                # refresh the tap
brew upgrade --cask ventilador
brew uninstall --cask ventilador          # add --zap to also remove preferences and logs
```

To stop using the tap: `brew untap ulm0/tap`.

## About this tap

`Casks/ventilador.rb` is generated by `scripts/release.sh` in the Ventilador repository, which fills in the
version and the SHA-256 of the notarized release zip.
